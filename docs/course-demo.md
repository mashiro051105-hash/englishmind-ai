# 课程演示与交付说明 v0.4

EnglishMind AI面向中国大学英语学习者，练习自然情境表达、词块与搭配。区分语法、搭配、语境、可选优化及正确表达。诊断后先独立作答，再集中反馈，通过变化情境检查本次检索；服务器决定重试、提示、降低要求、增加变化或结束。

浏览器React/TypeScript → 同源Express API → 受控教学状态机 → Mock或独立OpenAIProvider → 严格Zod与内容一致性检查 → 真实事件档案。AI只提供教学证据，不能修改提示次数、历史和状态。档案仅在当前浏览器，服务器只保存临时会话，真实模式会发送文本给模型服务商。

先按demo-cases.md跑三组Mock闭环，展示独立、提示后、重试后成功及正确表达不纠错。展示quality:plan的A–H，说明这是在线验收准备而非已取得真实质量结果。展示/api/health、会话隔离、安全访问门槛和本地清空。

已实现：两种Provider、诊断与训练闭环、维度分离、档案、并发／取消、质量工具、费用门槛、会话归属、基础限速、生产配置及本地HTTPS验收。

未实现／未验证：真实模型在线效果、公开托管访问、多实例或持久服务端会话、真实移动硬件及所有浏览器、长期教育效果。不得展示虚构的模型账单、公开URL或长期学习曲线。

Codex版是独立Web项目；Coze版是另行制作和发布的智能体，不把Codex版改成Coze前端。提交时分别记录身份设定、开场语、真实交互和可访问发布证据。对照相同语境、相同A–H正反例，区分Mock、SDK模拟和真实在线结果。

维护：单实例常驻运行；重启／休眠后重新开始未完成轮；档案留在当前设备。密钥仅服务端，定期复核依赖及价格。运行和部署见README/deployment.md，当前测试记录见verification.md。
