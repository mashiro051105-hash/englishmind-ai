# EnglishMind AI v1.0.0 — 首次演示发布草稿

**当前已在GitHub创建Draft，不是正式发布的版本。源码开发版本为v0.5.0。真实Ollama/在线模型质量和Render公开访问尚待验收；这些未完成项不能作为已验证能力宣传。**

面向中国英语学习者的自然表达训练课程应用：诊断→独立作答→针对性反馈→新情境迁移→下一任务。区分语法、搭配、语境、可优化及正确表达；提示和重试基于真实事件记录，单次成功不代表长期掌握。

- 默认Mock：明确标注有限规则，适合无API Key的界面和课程流程展示。
- Ollama：已实现官方本机API适配器和Windows RTX4060 8GB方案，建议Qwen3 4B Q4_K_M；需要用户安装和真实A–H人工验收，不自动下载。
- OpenAI：保留官方SDK适配器和结构化校验，余额为0，本次未调用；收费入口默认关闭。
- 本地档案、刷新恢复、单实例服务器会话、并发锁/幂等/取消/迟到响应保护。
- Render Free Mock单实例配置；尚无公开部署URL。

实际测试：63项离线自动测试、类型检查、生产构建；Chromium桌面/移动及本地HTTPS生产验证。完整结果以docs/verification-v0.5.0.md为准。模拟模型响应测试不是实际推理质量验证。

限制：单实例内存会话会在部署/重启/休眠后失效，浏览器档案保留；Mock不理解任意文本；本地模型可能产生错误英语或教学判断；没有长期学习效果证据。Coze仍是独立课程对照智能体。代码许可证尚未由作者选择。

附件计划：已验证源代码ZIP、SHA-256及提交清单，源代码不含权重、node_modules、真实.env或密钥。
